What is the SDK doing here?

The sample app bundles this directory and publishes it with staticSite. Portal's native engine serves the HTML, CSS and JavaScript through a relay; the app does not run a separate HTTP or game server.

val client = PortalClient(context)
val tunnel = client.publish(PortalConfig.staticSite(directory))

The SDK owns identity persistence, readiness waiting and failed-start rollback. The app owns its files and client lifetime. Keep the host app running; on Android, opt into the sample's foreground service for background hosting. iOS sessions are foreground-only.

Each visitor plays independently. This is not multiplayer, and scores are not uploaded or persisted. Anyone who knows the public URL can open it; hiding a listing is not access control.

Stop publishing in the host app to close this Portal session. Already-loaded games run locally in your browser.
